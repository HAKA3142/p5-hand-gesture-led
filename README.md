# p5.js HandPose를 이용한 Arduino UNO LED 밝기 조절

> **미션:** 엄지와 집게손가락 사이의 거리를 이용해 p5.js 슬라이더를 조절하고, 그 값을 Arduino UNO로 보내 LED 밝기를 제어한다.

## 1. 프로젝트 소개

이 프로젝트는 **p5.js**와 **ml5.js HandPose**를 이용해 웹캠에서 손을 인식하고, **엄지손가락 끝과 집게손가락 끝 사이의 거리**를 LED 밝기 값으로 바꾸는 실습이다. 손가락을 벌리면 슬라이더 값이 커지고, 오므리면 작아진다. 변환된 값은 USB 직렬 통신으로 Arduino UNO에 전달되며, UNO는 PWM 출력을 이용해 LED 밝기를 조절한다.

기존의 마우스 슬라이더 제어 과제를 **손동작 기반 제어**로 확장하는 것이 목표이다.

## 2. 구현 목표

- 웹캠 영상에서 손의 **21개 관절 위치** 인식
- 관절 위치를 점과 연결선으로 화면에 표시
- 엄지 끝(4번)과 집게손가락 끝(8번) 사이 거리 계산
- 손가락 간격에 따라 **세로 슬라이더(0~100%)** 자동 조절
- 슬라이더 값을 **PWM 밝기 값(0~255)**으로 변환
- Web Serial API를 이용해 Arduino UNO에 값 전송
- Arduino UNO의 **D3(~3) 핀**에 연결한 LED 밝기 조절

## 3. 사용 장비 및 기술

| 구분 | 내용 |
|---|---|
| 마이크로컨트롤러 | Arduino UNO R3 |
| 출력 장치 | LED 1개, 220~330Ω 전류 제한 저항 |
| 회로 구성 | 브레드보드, 점퍼선, USB 데이터 케이블 |
| 입력 장치 | PC 웹캠 |
| 웹 프로그램 | p5.js, ml5.js HandPose |
| 통신 방식 | Web Serial API, 9600 baud |
| LED 제어 | PWM, `analogWrite()` |

## 4. 회로 연결

```text
Arduino UNO D3(~3) ── 저항(220~330Ω) ── LED (+)
Arduino UNO GND  ─────────────────────── LED (-)
Arduino UNO USB  ─────────────────────── 컴퓨터
```

일반 LED에는 전류 제한 저항을 직렬로 연결한다. 손 인식은 PC의 웹캠에서 수행하므로 아두이노에 별도의 손 인식 센서를 연결할 필요가 없다.

## 5. 동작 원리

1. p5.js가 웹캠 영상을 불러온다.
2. ml5.js HandPose가 손의 관절 좌표를 추정한다.
3. `keypoints[4]`(엄지 끝)와 `keypoints[8]`(집게손가락 끝)의 거리를 `dist()`로 구한다.
4. `map()`을 이용해 거리를 슬라이더 값 **0~100%**로 변환한다. 거리 범위(예: 20~180px)는 사용 환경에 맞춰 조정한다.
5. 슬라이더 값을 **0~255**로 변환해 Arduino UNO에 1바이트로 전송한다.
6. Arduino UNO가 `Serial.read()`로 값을 받고 `analogWrite(3, value)`를 실행한다.

**처리 흐름:** 웹캠 → HandPose → 손가락 간격 → 세로 슬라이더 → Web Serial → Arduino UNO → LED

## 6. 실행 방법

1. Arduino IDE에서 시리얼 수신 및 PWM 제어 코드를 UNO에 업로드한다.
2. UNO의 D3, LED, 저항, GND를 연결하고 USB 케이블을 PC에 연결한다.
3. `index.html`을 통해 p5.js 및 ml5.js를 불러온 뒤 스케치를 실행한다.
4. 카메라 접근 권한을 허용하고 손을 웹캠에 보여준다.
5. 손가락 사이 거리에 따라 관절 표시와 세로 슬라이더 값이 변하는지 확인한다.
6. Chrome 또는 Edge의 **Arduino 연결** 버튼에서 UNO의 COM 포트를 선택한다.
7. 손가락을 벌리고 오므리며 실제 LED 밝기 변화를 확인한다.

> **주의:** Arduino IDE의 시리얼 모니터는 닫아둔다. Web Serial을 이용한 실제 LED 제어에는 지원 브라우저, HTTPS 환경, 사용자의 COM 포트 접근 권한이 필요하다.
